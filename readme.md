# 💞 Nossoflix — Site para Casal no Estilo Netflix

Site personalizado com visual e comportamento inspirados na Netflix, com abertura animada, seleção de perfis, painel master e armazenamento em Supabase.

---

## 🗺️ Roadmap

### Fase 1 — Supabase (Setup inicial)
- [x] Criar conta no Supabase
- [x] Criar projeto
- [x] Executar o SQL de setup inicial (SQL Editor → RUN)
- [x] Executar o SQL de migração (perfis + splash + avatares)
- [x] Criar usuário(s) em Authentication → Users
- [x] Copiar `Project URL` e `anon public key` em Settings → API

### Fase 2 — Arquivos locais
- [x] Criar os 6 arquivos + README
- [x] Colar URL e chave em `script.js` e `admin.js`

### Fase 3 — GitHub Pages
- [x] Criar repositório público
- [x] Upload dos arquivos
- [x] Ativar Pages em Settings → Pages → main / root

### Fase 4 — Uso
- [x] Enviar mídias
- [x] Criar categorias
- [x] Personalizar perfis
- [x] Configurar abertura
- [x] Personalizar textos e cores
