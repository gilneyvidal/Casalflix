# 💞 Nossoflix — Site para Casal no Estilo Netflix

Site personalizado com visual e comportamento inspirados na Netflix, feito com Supabase + GitHub Pages.

---

## 🗺️ Roadmap

### Fase 1 — Preparação (30 min)
- [x] Criar conta no Supabase
- [x] Criar projeto no Supabase
- [x] Executar o SQL de setup no SQL Editor
- [x] Criar usuário(s) em Authentication → Users
- [x] Copiar `Project URL` e `anon public key` em Settings → API

### Fase 2 — Arquivos (10 min)
- [x] Criar os 6 arquivos (index.html, style.css, script.js, admin.html, admin.css, admin.js)
- [x] Substituir as variáveis `SUPABASE_URL` e `SUPABASE_ANON_KEY` em `script.js` e `admin.js`

### Fase 3 — Publicação (10 min)
- [x] Criar repositório público no GitHub
- [x] Fazer upload dos arquivos
- [x] Ativar GitHub Pages (Settings → Pages → main / root)

### Fase 4 — Uso
- [x] Acessar o site e clicar em "adm" no rodapé
- [x] Fazer login com o usuário do Supabase
- [x] Enviar fotos e vídeos
- [x] Criar categorias (fileiras)
- [x] Personalizar textos, cor principal e rodapé
